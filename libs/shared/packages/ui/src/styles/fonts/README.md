# Vazirmatn Variable

Official source: https://github.com/rastikerdar/vazirmatn
Source commit: `6e553e33489a8f9dfaccc76860a2e3f3c1e66de7`
Original file: `fonts/variable/Vazirmatn[wght].ttf`.

The original variable font was losslessly packaged as WOFF2 with FontTools.
Glyphs, names and the 100–900 weight axis are preserved. SIL Open Font License
is included as `OFL.txt`. The original `ss01` feature substitutes Latin/Arabic
digit glyphs with Persian ones. The UI enables it via `font-feature-settings`;
numeric values in input elements, requests and stored data are unchanged.
