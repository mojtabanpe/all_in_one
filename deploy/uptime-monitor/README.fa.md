# پایشگر بیرونی دسترس‌پذیری (دستور ۱۹۲)

GlitchTip و هشدارهای api روی خود سرور اجرا می‌شوند، پس اگر خود سرور از کار بیفتد خبری نمی‌فرستند. این Worker روی
شبکهٔ Cloudflare (بیرون از ایران) هر ۵ دقیقه `/api/health`، `/` و `/app/` را بررسی می‌کند و از طریق ربات
توسعه‌دهنده (`poshtetgarm_develop_bot`، همان دستور ۱۸۶) به ادمین خبر می‌دهد:

- پس از ۲ دور ناموفق پیاپی (حدود ۱۰ دقیقه؛ هر مسیر در هر دور یک بار دوباره امتحان می‌شود): هشدار قطعی.
- تا زمان ادامهٔ قطعی: هر ۱ ساعت یک یادآوری.
- پس از بازگشت همهٔ مسیرها به وضعیت `200`: پیام «دوباره بالا آمد» همراه با مدت قطعی.

وضعیت در KV (`STATE`، کلید `state`) نگه داشته می‌شود. Worker هیچ مسیر HTTP عمومی ندارد (`fetch` پاسخ ۴۰۴ می‌دهد).

## راه‌اندازی / به‌روزرسانی

```sh
cd deploy/uptime-monitor
npx wrangler deploy
npx wrangler secret put BOT_TOKEN
npx wrangler secret put CHAT_ID   # شناسه‌های چت، با ویرگول جدا شده
```

آزمایش منطق محلی:

```sh
node --test deploy/uptime-monitor/worker.test.mjs
```
